# คู่มือติดตั้ง PC AutoBackup สำหรับผู้ใช้ใหม่

สำหรับ **v2026.11.08-resume บน Windows x64** ตรวจขั้นตอนเทียบกับแอปรุ่นนี้เมื่อ 8 พฤศจิกายน 2026

เป้าหมาย: สำรองโฟลเดอร์ที่เลือกไป Google Drive แบบเข้ารหัส **วันละครั้ง 21:00 ตามเวลาของ Windows** เก็บประวัติเริ่มต้น **7 วัน** และเตรียมกุญแจสำหรับกู้คืนเมื่อเครื่องเสีย

## เตรียมก่อนเริ่ม

- บัญชี Google ที่มีพื้นที่ Drive เพียงพอ และอินเทอร์เน็ต
- USB หรือที่เก็บปลอดภัยนอก PC สำหรับกุญแจกู้คืน
- ตัวติดตั้งสำหรับ Windows x64 ไม่ต้องติดตั้ง .NET เพิ่ม ไม่ต้องใช้สิทธิ์ Administrator
- รุ่นนี้ไม่มี OAuth client กลางในตัวติดตั้ง ผู้ใช้ใหม่ต้องตั้ง Google Cloud ของตนเองหนึ่งครั้งตามขั้นตอน 2
- แอปสำรองไฟล์ที่เลือก ไม่ใช่การโคลน Windows ไดรเวอร์ หรือย้ายโปรแกรมทั้งหมด

## 1. ดาวน์โหลดและติดตั้ง .exe

1. เปิด [หน้า Release รุ่น Resume](https://github.com/sanchatmd-dev/PCAutobackup/releases/tag/v2026.11.08-resume)
2. ใน **Assets** ดาวน์โหลด **PCAutobackup-win-x64.exe** ประมาณ 206.64 MB อย่าเลือก Source code ZIP แทน
3. หากอัปเดตเครื่องที่ติดตั้งอยู่แล้ว ให้ปิดหน้าตั้งค่าและรอให้งานสำรอง/กู้คืนเสร็จก่อนติดตั้งทับ ไม่ต้องลบการตั้งค่าเดิม
4. ดับเบิลคลิก `.exe` รอติดตั้งจนเสร็จ แอปจะเปิด พร้อมไอคอนเมฆ **PC AutoBackup** บน Desktop และ Start Menu
5. เปิดจากไอคอน Desktop ได้ในครั้งถัดไป ภาษาไทยเป็นค่าเริ่มต้น เปลี่ยนเป็น English ได้ที่ **การตั้งค่า → ภาษาของแอป**

ตัวติดตั้งยังไม่มีลายเซ็น code signing จึงอาจพบคำเตือนผู้เผยแพร่จาก Windows ตรวจแหล่งดาวน์โหลดก่อนดำเนินการ ไม่ต้องปิดระบบป้องกันของ Windows หากเครื่ององค์กรบล็อก ให้ติดต่อผู้ดูแล

หากต้องการตรวจไฟล์ ดาวน์โหลด `SHA256SUMS.txt` จาก Release เดียวกัน เปิด PowerShell แล้วรันคำสั่งนี้ โดยแก้พาธให้ตรงกับไฟล์:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "$env:USERPROFILE\Downloads\PCAutobackup-win-x64.exe"
```

ค่า Hash ต้องตรงกับบรรทัดของ `.exe` ใน `SHA256SUMS.txt`

## 2. เตรียม Google OAuth ครั้งแรก

ใช้บัญชีและโปรเจกต์ของคุณเอง แอป **ไม่ขอรหัสผ่าน Google** ชื่อเมนู Google อาจเปลี่ยนจากคู่มือได้

### 2.1 สร้างโปรเจกต์และเปิด API

1. เข้า [Google Cloud Console](https://console.cloud.google.com/) ด้วยบัญชีของคุณ
2. เปิดตัวเลือกโปรเจกต์ด้านบน เลือก **New project** ตั้งชื่อ เช่น `PC AutoBackup` กด **Create** แล้วเลือกโปรเจกต์ใหม่นี้
3. ไป **APIs & Services → Library** ค้นหา **Google Drive API** แล้วกด **Enable**

### 2.2 ตั้งชื่อแอปและ Audience

1. เปิด **Google Auth Platform** หรือ **OAuth consent screen** แล้วกด **Get started** หากยังไม่ได้ตั้งค่า
2. ใส่ชื่อแอป เช่น `PC AutoBackup` เลือก User support email และ Contact email ของคุณ
3. บัญชี Gmail ส่วนบุคคลเลือก Audience แบบ **External** อ่านและยอมรับนโยบายเมื่อคุณเห็นด้วย แล้วบันทึก
4. หากยังเป็น **Testing** เข้า **Audience → Test users → Add users** เพิ่มอีเมลที่จะใช้สำรองแล้วกด **Save**

**งานระยะยาว:** ตรวจ **Audience → Publish app** และเปลี่ยนจนแสดง **In production** หาก Google ขอ Branding เช่นหน้าเว็บ นโยบายความเป็นส่วนตัว หรือโดเมน ให้ใช้ข้อมูลจริงที่คุณมีสิทธิ์ใช้และทำตามข้อกำหนดบนหน้าจอ หากยังทำไม่ได้ ให้ใช้ Testing ทดสอบก่อนและขอผู้ดูแลช่วย ไม่ใส่เว็บไซต์สมมติหรืออ้างโดเมนของผู้พัฒนาเป็นของคุณ

External/Testing ที่ขอสิทธิ์ Drive มี refresh token อายุ 7 วัน จึงอาจต้องเชื่อมใหม่ Production ยกเลิกข้อจำกัดจากสถานะ Testing นี้ แต่ไม่ได้รับประกันว่าจะไม่ต้องเชื่อมใหม่ด้วยเหตุอื่น และไม่เท่ากับ Google รับรองแอปแล้ว อ้างอิง [อายุ token ของ Google](https://developers.google.com/identity/protocols/oauth2#expiration) และ [สถานะแอป OAuth](https://developers.google.com/identity/protocols/oauth2/production-readiness/overview)

### 2.3 สร้าง Desktop client

1. เข้า **Google Auth Platform → Clients → Create client**
2. เลือก **Application type: Desktop app** ตั้งชื่อ เช่น `PC AutoBackup Windows` แล้วกด **Create**
3. ดาวน์โหลด **JSON** และเก็บไว้ในที่ปลอดภัย ไม่เลือก Web application และไม่ต้องใส่ redirect URL ของเว็บไซต์
4. เก็บสำเนา JSON นอกเครื่อง จดว่าเป็นของ Google Cloud project ใด ต้องใช้ OAuth application/project เดิมเมื่อกู้คืนคลัง Drive บนเครื่องใหม่ในรุ่นนี้

อ่านเพิ่ม: [คู่มือ OAuth ของโครงการ](https://github.com/sanchatmd-dev/PCAutobackup/blob/main/docs/google-setup.md) และ [Desktop OAuth ของ Google](https://developers.google.com/identity/protocols/oauth2/native-app)

## 3. เชื่อม Google Drive ในแอป

1. ไป **พื้นที่จัดเก็บ** เลือก **Google Drive** ซึ่งเป็นปลายทางเริ่มต้น
2. ขยาย **การตั้งค่า Google OAuth สำหรับแอป** กด **นำเข้าไฟล์ client JSON…** เลือกไฟล์จากขั้นตอน 2.3
3. ช่อง **อีเมลสำหรับแนะนำบัญชี** กรอกหรือเว้นว่างได้ การพิมพ์อีเมลยังไม่ใช่การเชื่อมต่อ
4. กด **เชื่อมต่อ Google** เลือกบัญชีในเบราว์เซอร์ ตรวจชื่อแอปและอนุญาตสิทธิ์ตามหน้าจอ Google
5. กลับมาที่แอป ตรวจว่าแสดงอีเมลบัญชีที่ต้องการจริง หากผิดบัญชี ให้ยกเลิกการเชื่อมต่อแล้วเลือกใหม่

สิทธิ์คือ `openid`, `email`, `drive.file` สำหรับไฟล์ที่แอปสร้างหรือได้รับสิทธิ์ ไม่ต้องเปิด Google Drive for desktop ค้างไว้ และไม่ส่งรหัสผ่าน Google ให้ผู้ส่งตัวติดตั้ง

คลังเข้ารหัสอยู่ภายใต้ `PC AutoBackup` ใน Drive แยกตามเครื่อง ชื่อไฟล์ในคลังอาจอ่านไม่รู้เรื่อง ไม่ควรย้าย แก้ หรือลบชิ้นส่วนของคลังด้วยตนเอง

## 4. เลือกโฟลเดอร์สำรอง

1. เปิด **โฟลเดอร์ต้นทาง → เพิ่มโฟลเดอร์**
2. เลือกโฟลเดอร์ เช่น Documents, Pictures หรือโฟลเดอร์งาน เลือกหลายโฟลเดอร์ใน dialog ได้ หรือกดเพิ่มอีกครั้ง
3. ตรวจพาธในรายการให้ถูกต้อง หากเลือกผิดให้นำออกจากรายการ การนำรายการออกไม่ลบไฟล์ต้นฉบับ

เริ่มจากโฟลเดอร์เล็กที่มีไฟล์ทดสอบ แล้วค่อยเพิ่มข้อมูลจริงหลังทดลองกู้คืน เลือกเฉพาะข้อมูลจำเป็น หลีกเลี่ยงทั้งไดรฟ์ Windows และโฟลเดอร์แม่/ลูกซ้ำกัน หากต้นทางเป็นดิสก์ภายนอก ให้ต่อไว้ตอนสำรอง ไฟล์ที่ถูกล็อกหรืออ่านไม่ได้อาจทำให้งานล้มเหลว

## 5. ส่งออกและเก็บกุญแจกู้คืน

1. เตรียม USB หรือที่เก็บปลอดภัยที่เข้าถึงได้แม้ PC นี้เสีย
2. ไป **การตั้งค่า → เก็บกุญแจให้พร้อม ก่อนวันที่ต้องใช้ → ส่งออกกุญแจกู้คืน…**
3. บันทึกไฟล์ **`.pcakey`** ไปยังที่เตรียมไว้ ตั้งชื่อให้ระบุเครื่องหรือคลังได้
4. ตรวจว่าไฟล์อยู่จริง และสถานะในแอประบุว่าเคยส่งออกหรือนำเข้ากุญแจแล้ว
5. เก็บสำเนาอีกชุดแยกสถานที่ แล้วเก็บ USB ให้ปลอดภัย

**อย่าเก็บกุญแจเพียงสำเนาเดียวใน PC ที่สำรอง หรือเฉพาะในคลังเข้ารหัสที่ต้องใช้กุญแจนี้เปิด** ผู้ที่มีทั้งกุญแจและคลังอ่านข้อมูลได้ หากกุญแจหายและใช้เครื่องเดิมไม่ได้ แอปไม่มีระบบรีเซ็ตเพื่อถอดรหัสแทน

| สิ่งที่เก็บนอกเครื่อง | ใช้ทำอะไร |
| --- | --- |
| `.pcakey` เก็บเป็นความลับ | ถอดรหัสข้อมูลสำรอง |
| Desktop OAuth client JSON เก็บอย่างปลอดภัย | เชื่อม application/project เดิมบนเครื่องใหม่เพื่อค้นคลังเดิม |
| ชื่อบัญชี Google ชื่อเครื่อง/คลัง และโปรเจกต์ | ช่วยเลือกข้อมูลให้ถูก โดยไม่จดรหัสผ่านรวมกับกุญแจ |

client JSON **ใช้แทน `.pcakey` ไม่ได้** การล็อกอิน Drive สำเร็จอย่างเดียวก็ยังถอดรหัสไม่ได้

## 6. สำรองและทดลองกู้คืนครั้งแรก

1. ตรวจบัญชี Google โฟลเดอร์ และการส่งออกกุญแจ แล้วกด **สำรองตอนนี้**
2. รอจนแจ้งสำเร็จ หากเกิดข้อผิดพลาดให้แก้ก่อนพึ่งพางานอัตโนมัติ รอบแรกอาจนานตามขนาดข้อมูลและความเร็วเน็ต
3. ไป **ประวัติและกู้คืน → รีเฟรช** ตรวจว่ามีชุดสำรองสำเร็จ
4. เลือกชุด กด **กู้คืนชุดที่เลือก…** แล้วเลือก **โฟลเดอร์ว่างใหม่แยกจากต้นฉบับ** เช่น `PCAB-Restore-Test` ที่สร้างไว้ใน Documents
5. เปิดไฟล์ที่กู้คืนและเทียบกับต้นฉบับ แอปสร้างโฟลเดอร์แยกตามต้นทางภายในปลายทาง ไม่เขียนทับไฟล์เดิมอย่างเงียบ ๆ

การกู้คืนชุดที่เลือกจะกู้คืนข้อมูลของชุดนั้น จึงควรทดสอบด้วยชุดเล็กก่อนเพิ่มโฟลเดอร์ใหญ่

## 7. เปิดอัตโนมัติวันละครั้ง 21:00

1. ไป **การตั้งค่า → สำรองตามเวลาของคุณ**
2. ติ๊ก **เปิดสำรองอัตโนมัติทุกวัน**
3. ช่อง **เวลาสำรองแต่ละวัน (HH:mm)** ให้มีเพียง **`21:00`** สำหรับวันละครั้ง
4. ตั้ง **เก็บประวัติ (จำนวนวัน)** เป็น **`7`** ตามค่าเริ่มต้น
5. **จำกัดพื้นที่คลังสำรอง (GB, ไม่บังคับ)** เว้นว่างได้ หรือใส่เพดานที่พอกับข้อมูลและพื้นที่ Drive
6. กด **บันทึกการตั้งค่า** รอข้อความสำเร็จ แล้วตรวจตารางในหน้า **ภาพรวม**
7. ตรวจเวลาและเขตเวลา Windows ให้ถูกต้อง หากต้องการ 21:00 เวลาไทย ใช้เขตเวลา **(UTC+07:00) Bangkok, Hanoi, Jakarta**

ติดตั้งใหม่ยังไม่เริ่มอัตโนมัติจนกว่าจะเลือกต้นทาง เชื่อมปลายทาง ส่งออกกุญแจ และเปิดตารางเอง ค่าเริ่มต้น 21:00 ไม่ได้หมายความว่าติดตั้งแล้วจะเริ่มโดยไม่ตั้งค่า

หลังเปิดตาราง ระบบอาจสำรองชดเชยรอบที่ถึงกำหนดไปแล้วเมื่อมี trigger ตรวจงานค้าง ไม่จำเป็นต้องรอ 21:00 ครั้งถัดไปเสมอ

ตรวจเพิ่มเติมได้ที่ **Task Scheduler → Task Scheduler Library** หางานชื่อขึ้นต้น `PCAutobackup-` ดูว่า Enabled และ Daily trigger เป็น 21:00 การมี logon/unlock/resume triggers เพิ่มถือว่าปกติ

## 8. ใช้งานประจำวันและ Resume

- ปิดหน้าต่างหลังตั้งค่าได้ ไอคอนเมฆในถาดระบบเริ่มเมื่อเข้าสู่ Windows ระหว่างมีงาน ปิดหรือย่อหน้าต่างแล้วงานยังทำต่อ
- เวลา 21:00 ต้องเปิดเครื่อง ล็อกอินผู้ใช้ Windows เดิม และเข้าถึงต้นทาง/อินเทอร์เน็ตได้
- หากปิดเครื่องหรือ Sleep ระบบตรวจรอบที่พลาดหลังเข้า Windows ปลดล็อก หรือกลับจาก Sleep ประมาณ 1 นาที รวมชดเชยหนึ่งรอบ แอปไม่ปลุกเครื่องเอง
- ถ้าถึงรอบใหม่แต่งานยังไม่เสร็จ งานเดิมทำต่อ ไม่มีงานสำรองซ้อน
- เน็ตขาดหรือ process ถูกปิด: รอบใหม่ใช้ก้อนที่สำเร็จแล้วต่อได้ ต้องอ่าน/hash ต้นทางและตรวจชิ้นส่วนค้างใหม่ ก้อนที่ยังไม่ครบส่งใหม่สูงสุด 4 MiB
- หากกดยกเลิกเอง ระบบไม่บังคับเริ่มใหม่ทันที กด **สำรองตอนนี้** เพื่อทำต่อได้
- Task Scheduler ตั้งลองใหม่เมื่องานล้มเหลวทุก 5 นาที สูงสุด 3 ครั้งต่อ trigger การเริ่มจริงขึ้นกับ Windows และเครือข่าย
- ไฟล์ที่ลบในต้นทางหายจากชุดล่าสุดเมื่อรอบใหม่สำเร็จ แต่ยังอยู่ในประวัติที่ไม่ถูกล้าง โควตาอาจทำให้ประวัติสั้นกว่า 7 วัน
- ชุดสำเร็จล่าสุดยังถูกเก็บไว้ ชิ้นส่วน Resume จากงานที่ล้มเหลวอาจกินพื้นที่เกินโควตาชั่วคราว ส่วนที่ไม่ใช้ล้างหลังสำรองสำเร็จ

## 9. กู้คืนเมื่อเปลี่ยนเครื่อง

1. ติดตั้งแอปบนเครื่องใหม่ เตรียม `.pcakey` และ client JSON เดิม
2. นำเข้า OAuth client **จาก application/project เดิม** และเชื่อม **บัญชี Google เดิม** การสร้างโปรเจกต์ใหม่ไม่รับประกันว่าจะเห็นคลังเก่าด้วยสิทธิ์ `drive.file`
3. ไป **ประวัติและกู้คืน → นำเข้ากุญแจกู้คืน…** เลือก `.pcakey` ของคลังเดิม
4. กด **ค้นหาคลังใน Google Drive** เลือกคลังเครื่องเดิม แล้วกด **รีเฟรช**
5. เลือกชุดและกู้คืนไป **โฟลเดอร์ว่างใหม่** ตรวจไฟล์ก่อนย้ายไปใช้งาน
6. เมื่อเริ่มสำรองเครื่องใหม่ ให้ใช้คลังใหม่ของเครื่องใหม่ ไม่เขียนงานสำรองของเครื่องว่างลงคลังเครื่องเก่า

## แก้ปัญหาเบื้องต้น

| อาการ | สิ่งที่ตรวจ |
| --- | --- |
| เชื่อม Google ไม่ได้ | เปิด Drive API แล้วหรือไม่, client เป็น Desktop app, JSON ถูกโปรเจกต์, บัญชีอยู่ใน Test users หาก Testing; องค์กรอาจต้องอนุญาตโดยผู้ดูแล |
| Google เตือนหรือบล็อก | ตรวจชื่อแอป โปรเจกต์ บัญชี และข้อกำหนด Audience/Branding ไม่อนุญาตแอปที่ไม่รู้จัก |
| ต้องเชื่อมใหม่ทุก 7 วัน | ตรวจ External/Testing เปลี่ยน Production ให้ครบ แล้วเชื่อม Google ใหม่ |
| เริ่มงานไม่ได้เพราะกุญแจ | ส่งออก `.pcakey` ผ่านแอปให้สำเร็จ การคัดลอก configuration ไม่ใช้แทน |
| ไม่สำรองตอน 21:00 | ตรวจบันทึกเปิดอัตโนมัติแล้ว เวลา Windows ถูกต้อง ล็อกอินผู้ใช้เดิม task Enabled และข้อผิดพลาดล่าสุดในแอป |
| พื้นที่ไม่พอ | ตรวจทั้งพื้นที่ Drive และเพดาน GB ในแอป เพิ่มพื้นที่หรือปรับข้อมูล/โควตาโดยรักษาชุดล่าสุดไว้ |
| เครื่องใหม่หาชุดเดิมไม่พบ | ตรวจบัญชี OAuth application/project คลัง และกุญแจให้ตรงกับเครื่องเดิม |
