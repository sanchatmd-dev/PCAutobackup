PC AutoBackupความเป็นส่วนตัวเงื่อนไขการใช้

นโยบายความเป็นส่วนตัว

มีผล 7 พฤศจิกายน 2026 นโยบายนี้อธิบายแอป Windows PC AutoBackup ใน repository sanchatmd-dev/PCAutobackup ผู้ใช้ตั้งค่า OAuth client และพื้นที่จัดเก็บของตนเอง

ข้อมูลที่แอปใช้

  • อีเมลและรหัสบัญชี Google เพื่อยืนยันตัวตนและเลือก Drive ที่ถูกต้อง
  • OAuth access/refresh token เพื่อเข้าถึง Drive ตามสิทธิ์ที่อนุญาต โดยเก็บในเครื่องด้วย Windows DPAPI สำหรับผู้ใช้ปัจจุบัน แอปไม่รับหรือเก็บรหัสผ่าน Google
  • เนื้อหาไฟล์ ชื่อไฟล์ โครงสร้างโฟลเดอร์ และข้อมูลเวลาที่จำเป็นจากต้นทางที่ผู้ใช้เลือก เพื่อสำรองและกู้คืน
  • ชื่อเครื่อง รหัสเครื่อง การตั้งค่า และสถานะงาน เพื่อแยกคลังสำรองและแสดงผล หากผู้ใช้เปิดตัวเลือกรายชื่อแอป จะรวมรายการโปรแกรมที่ติดตั้งไว้ในชุดสำรองด้วย

การจัดเก็บและการส่งข้อมูล

แอปเข้ารหัสเนื้อหาไฟล์และ manifest ก่อนจัดเก็บ เมื่อเลือก Google Drive จะส่งข้อมูลเข้ารหัสตรงจากเครื่องไปยังบัญชี Google ของผู้ใช้ ไม่มีเซิร์ฟเวอร์สำรองของผู้พัฒนาเข้ามารับเนื้อหาไฟล์ การเลือกดิสก์ภายนอกหรือโฟลเดอร์ใช้ปลายทางนั้นแทน

ชื่อและรหัสเครื่องในชื่อโฟลเดอร์หรือคุณสมบัติของคลัง รวมถึงขนาดและเวลาของวัตถุบน Drive เป็น metadata ที่ไม่ได้เข้ารหัสทั้งหมด Google ประมวลผลบริการตาม นโยบายของ Google

วัตถุประสงค์และการแบ่งปัน

แอปใช้ข้อมูล Google เฉพาะการยืนยันบัญชี การสำรอง การแสดงประวัติ การกู้คืน และการล้างข้อมูลเก่าตามการตั้งค่า ไม่มีโฆษณา การขายข้อมูล หรือการส่งข้อมูล Google ไปฝึกโมเดล AI ในตัวแอป และไม่มี analytics SDK ของผู้พัฒนา

การใช้และส่งต่อข้อมูลที่ได้รับจาก Google APIs อยู่ภายใต้ Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

ระยะเวลาเก็บและการลบ

ค่าเริ่มต้นเก็บประวัติ 7 วัน ผู้ใช้เปลี่ยนจำนวนวันและเพดานพื้นที่ได้ การล้างเกิดหลังรอบสำรองที่สำเร็จ โดยเก็บชุดล่าสุดที่กู้คืนได้ไว้ การลบต้นฉบับไม่ทำให้ข้อมูลหายจากทุกเวอร์ชันทันที ชุดสำรองคงอยู่จนถูกล้างตามนโยบายหรือผู้ใช้ลบจากปลายทาง

ผู้ใช้ปิดตารางสำรองและตัดการเชื่อมต่อในแอปได้ การตัดการเชื่อมต่อเคลียร์ token ที่แอปเก็บ แต่ไม่ลบชุดสำรองและไม่เท่ากับเพิกถอนสิทธิ์ที่ Google ผู้ใช้เพิกถอนสิทธิ์ได้ที่ การเชื่อมต่อในบัญชี Google และจัดการข้อมูลสำรองใน Drive ของตนเอง

กุญแจกู้คืนและการควบคุมของผู้ใช้

ผู้ใช้ควบคุม recovery key ต้องเก็บสำเนาไว้นอก PC ผู้พัฒนาไม่มีบริการกู้กุญแจ หากทำกุญแจหายอาจกู้ข้อมูลไม่ได้ การเก็บ token และกุญแจด้วย DPAPI ไม่สามารถป้องกันทุกกรณีที่บัญชี Windows หรือเครื่องถูกเข้าถึงโดยผู้ไม่หวังดี

เว็บไซต์และการติดต่อ

เว็บไซต์นี้เป็นหน้า static ไม่มีแบบฟอร์มรับไฟล์หรือ analytics ที่โครงการเพิ่มเอง ผู้ให้บริการโฮสต์ GitHub Pages อาจบันทึกข้อมูลการเข้าถึงตาม นโยบายของ GitHub ติดต่อผ่าน GitHub Issues โดยไม่เผยข้อมูลส่วนตัวหรือ credentials ในข้อความสาธารณะ
