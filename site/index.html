PC AutoBackupความเป็นส่วนตัวเงื่อนไขการใช้ซอร์สและคู่มือ

Windows desktop backup

สำรองไฟล์สำคัญ
พร้อมกู้คืนเมื่อเปลี่ยนเครื่อง

PC AutoBackup เป็นแอป Windows สำหรับสำรองโฟลเดอร์ที่คุณเลือกไปยัง Google Drive, External HDD/SSD หรือโฟลเดอร์อื่น ข้อมูลไฟล์และรายการไฟล์สำรองเข้ารหัสบนเครื่องก่อนจัดเก็บ คุณควบคุมกุญแจกู้คืนเอง

ตั้งเวลาสำรอง ใช้ทรัพยากรเมื่อจำเป็น

Windows Task Scheduler เรียก worker ตามเวลาที่ตั้งไว้ แล้ว worker ปิดตัวเองเมื่อเสร็จ ปิดหน้าตั้งค่าแล้วเหลือไอคอนเมฆในถาดระบบที่ใช้ RAM ต่ำ เริ่มพร้อมการเข้าสู่ Windows ตั้งเวลาสำรองได้หลายรอบต่อวัน โดยค่าเริ่มต้นเป็น 21:00 ค่าเริ่มต้นเก็บประวัติ 7 วัน ปรับจำนวนวันและเพดานพื้นที่ได้

ติดตั้งจากไฟล์เดียว เลือกภาษาได้

ส่งต่อไฟล์ PCAutobackup-win-x64.exe ให้ผู้ใช้ Windows x64 ดับเบิลคลิกเพื่อติดตั้ง สร้างไอคอนเมฆบน Desktop และเปิดแอปเมื่อเสร็จ รวม .NET runtime มาแล้ว เลือกภาษาไทยหรือ English ได้ในแอป โดยค่าเริ่มต้นเป็นภาษาไทย ผู้ใช้แต่ละคนเชื่อมบัญชี Google และเลือกโฟลเดอร์ของตนเอง

ดาวน์โหลดตัวติดตั้งและไฟล์ตรวจ SHA-256 จาก GitHub Release ล่าสุด

เหตุผลที่ขอสิทธิ์ Google

แอปใช้ openid และ email เพื่อยืนยันบัญชีปลายทาง และ drive.file เพื่อสร้าง อ่าน แก้ไข และลบไฟล์สำรองที่แอปสร้างหรือได้รับสิทธิ์ใน Drive ของคุณ การลบประวัติเก่าทำตามจำนวนวันและเพดานพื้นที่ที่ตั้งไว้ แอปไม่ขอสิทธิ์อ่านไฟล์ทั้งหมดใน Drive และไม่รับรหัสผ่าน Google

รองรับการคืนไฟล์ ไม่ใช่การโคลน Windows หรือคืนโปรแกรมทั้งหมด ต้องเก็บ recovery key นอกเครื่อง และทดสอบกู้คืนก่อนพึ่งพาชุดสำรอง

โครงการและช่องทางติดต่อ: GitHub Issues ของ PC AutoBackup อย่าแนบไฟล์ส่วนตัว รหัสผ่าน token หรือ recovery key ใน issue สาธารณะ
